00 · TL;DR

한 문단 요약

GRPO 기반 VLM 사후학습은 모든 질문에 완전한 reasoning trace를 강제해 토큰·연산 비용이 과도해진다. 이 논문은 인간이 쉬운 문제엔 추론을 건너뛰고 어려운 문제에만 신중히 생각하듯, 모델이 "언제 생각할지(when to think)"를 스스로 결정하는 selective reasoning을 VLM에서 최초로 제안한다. 핵심 방법 TON(Think-or-Not)은 (i) reasoning trace를 확률적으로 빈 thought(\n\n)로 대체하는 thought dropout SFT로 "생각할지 말지" 포맷을 cold start시키고, (ii) 별도 정규화 없이 outcome reward만으로 GRPO를 돌려 언제 생각할지를 자유롭게 탐색하게 한다.

핵심 발견

불필요한 추론을 건너뛰는 것이 성능을 유지할 뿐 아니라 오히려 향상시킬 수 있다("free-lunch"). 학습이 진행될수록 skip-thought 비율이 reward 상승과 함께 점진적으로 증가한다.

세 줄 기여

  1. VLM에서 "어떻게 생각할지(how)"가 아니라 "언제 생각할지(when)"를 다루는 최초의 연구 — AITZ 질문의 51%가 reasoning trace 없이도 정답이라는 실증 관찰에서 출발.
  2. reasoning trace를 확률적으로 빈 \n\n으로 대체하는 thought dropout SFT를 cold start로 삼고, 별도 길이 정규화 없이 outcome reward만으로 GRPO를 돌리는 2단계 프레임워크 TON.
  3. GSM8K(LLM) · CLEVR/Super-CLEVR/GeoQA(VLM) · AITZ(agentic) 전반의 3B/7B 모델에서 완성 길이를 최대 90% 줄이며 성능 손실 없음(GeoQA +17 Acc), skip 비율이 reward와 함께 증가함을 ablation으로 검증.
01 · 개념

먼저 알아야 할 사전지식

이 논문은 RL 사후학습(GRPO) 위에 아주 얇은 SFT 단계를 얹는 구조다. 아래 카드가 읽기 위한 최소 전제 지식이다.

GRPO Group Relative Policy Optimization

value function 없이 한 그룹의 여러 샘플 응답 간 상대 advantage로 정책을 업데이트하는 RL 기법(DeepSeek). answer verifier를 reward로 쓴다. 이 논문의 2단계 학습이 그 위에 얹힌다.

CoT Chain-of-Thought

답 이전에 중간 추론을 명시적으로 생성하는 패러다임. 여기서는 <think>...</think> reasoning trace가 이에 해당한다.

SFT Supervised Fine-Tuning

정답 시퀀스에 대한 지도학습. TON의 1단계 thought dropout이 여기서 이뤄지며, RL 이전의 포맷 prior를 심는다.

format vs outcome reward

rule-based reward의 두 종류. format reward rf는 <think><answer> 태그 형식 준수를, outcome reward ro는 정답 일치 여부를 보상한다.

VLM Vision-Language Model

이미지와 텍스트 질문을 함께 받아 답을 생성하는 멀티모달 모델. 본 논문 backbone은 Qwen-2.5-VL-Instruct 3B/7B.

MDP Markov Decision Process

상태·행동·정책·보상으로 정의되는 순차 의사결정 프레임. 논문은 vision-language reasoning을 (V, Q, S*, π, r) 튜플의 MDP로 형식화한다.

Deep-dive: RLHF → PPO → DPO → GRPO 계보

RLHF는 preference annotation으로 reward model을 학습한 뒤 PPO로 정책을 정교화한다. DPO는 reward model 없이 정책 업데이트를 이진 분류로 재구성해 워크플로를 단순화한다. GRPO는 value function을 피하고 그룹 내 상대 advantage로 다양한 추론 경로·답변 품질을 높인다. 이 논문은 이 계보 전체가 공유하는 암묵적 가정 — "모든 질문 = full thinking" — 을 문제 삼는다.

Deep-dive: 실험 backbone과 벤치마크 지도

Qwen-2.5-VL 3B/7B가 backbone. Qwen3는 thinking을 외부 스위치로 켜고 껐지만, 이 논문은 이를 학습된 내재적 능력으로 대체한다.

벤치마크는 난이도 스펙트럼을 커버한다 — CLEVR/Super-CLEVR(합성 3D counting, easy·OOD), GeoQA(중국 중학 기하 수학, hard), AITZ(Android-in-the-Zoo, 모바일 GUI 에이전트, multi-step), GSM8K(text-only LLM 확장 검증).

데이터 규모: CLEVR counting subset 1,000개 학습 / CLEVR 200 + Super-CLEVR 200 테스트, GeoQA 4,998개 중 각도·변 길이 1,000개(선택지 제거해 난이도↑), AITZ는 2,504 궤적·18.6K intention 중 General 도메인 1,000개 학습 후 Web shopping·Google apps·Install로 OOD 테스트.

Deep-dive: 왜 <think>\n\n</think>가 "유효한" 출력인가

format reward rf가 outcome reward와 분리돼 항상 공유된다는 설계가 열쇠다. 태그 형식 준수 자체를 별도 신호로 보상하므로, thought 내용이 비어 있어도 <think>\n\n</think><answer>…</answer>는 여전히 형식상 유효하다. 즉 skip은 "포맷 위반"이 아니라 "포맷 안의 한 선택지"가 된다.

🔍 리뷰 중 발견 — 이 연결(3절 format reward 정의 → 4절 thought dropout의 성립 조건)은 논문이 명시적으로 이어 붙이지 않고 암묵적 전제로 작동한다.

02 · 배경

선행 연구의 흐름

저자들은 효율 연구가 "어떻게 짧게 생각할지(how)"에 머물렀다고 보고, 한 단계 앞의 "애초에 생각이 필요한가(whether)"로 축을 옮긴다.

  1. RLHF / PPO — 사후학습 정렬의 출발점
    preference annotation으로 reward model을 학습하고 PPO로 정책을 정렬한다.
  2. DPO — reward model 제거
    정책 업데이트를 이진 분류로 재구성해 정렬 워크플로를 단순화.
  3. GRPO (DeepSeekMath / R1 계열)
    value function 없이 그룹 상대 advantage로 추론 경로를 다양화. 이후 UI-R1·GUI-R1 등 VLM·GUI agent로 확산.
  4. 효율 계열 — long2short · "I don't know" · token-budget
    디코딩 길이 압축, 비생산적 추론의 조기 종료, token-budget 인지 정책. 모두 "추론은 한다"는 전제를 유지하는 "how" 범주.
  5. 외부 스위치 — Qwen3의 thinking on/off
    사용자가 thinking 모드를 켜고 끄는 외부 제어. 모델 스스로의 판단은 아니다.
  6. TON (본 논문, 2025)
    "추론이 필요한지 여부"를 모델이 먼저 판단하는 selective reasoning으로 축을 상위 층위("whether")로 이동 — 스위치를 학습된 내재 능력으로 바꾼다.
리뷰 노트 — 프레이밍의 수사

기존 efficiency 연구를 부정하지 않고 "how" 범주로 묶은 뒤, 자신을 직교(orthogonal)한 축인 "whether"로 위치시키는 전형적 related-work 전략이다. References의 overthinking·CoT 길이 계열 인용([6]–[9])이 이 논문의 지적 좌표를 보여준다 — "긴 추론이 항상 좋지는 않다"는 실증 흐름 위에서 한 걸음 더 밀어붙인 것.

⚠️ 논문 밖 일반론

"whether"와 "how"가 실제로 완전히 분리 가능한지(짧게 생각하기의 극단이 안 생각하기 아닌지)는 논문에서 개념적으로만 구분될 뿐 정량적으로 선을 긋지 않는다 — 이 경계의 모호함은 논문에 명시되지 않음.

03 · 방법론

TON: 2단계 선택적 추론 프레임워크

출발점이 된 관찰

Qwen-2.5-VL-3B로 AITZ에서 추론 유무를 대조한 결과, "think"를 제거해도 52.1%의 답이 정답으로 유지됐고, 특히 14.5%는 오히려 think가 없을 때에만 정답이었다. 후자는 "추론이 불필요하다"를 넘어 "추론이 해로울 수 있다"는 더 강한 주장을 뒷받침한다 — 잘못된 CoT가 정답을 오답으로 바꾸는 경우가 실제로 존재한다는 뜻이다.

문제 정식화 (MDP)

비전-언어 추론 환경을 튜플 (V, Q, S*, π, r)의 MDP로 형식화한다. 응답 O는 <think>T</think><answer>S</answer> 태그 형식을 따라야 하며, 이는 답 이전에 추론하도록 강제하고 regex 파싱을 쉽게 한다.

V 시각 컨텍스트(이미지) · Q 질문 · S* 정답 · π 정책 · r 스칼라 보상. 정답이면 양의 보상, 오답이면 0.

🔍 리뷰 중 발견 — MDP라기보다 single-step bandit

상태 전이나 감가율이 정의되지 않고 한 번의 (V,Q)→O 생성 후 즉시 스칼라 보상이 주어진다. AITZ 같은 multi-step 과제도 여기서는 한 스텝 응답 단위로 다뤄진다(논문은 "bandit"이라 명시하지 않음).

1단계 — Thought Dropout SFT

"think" vs "non-think"를 출력 포맷의 일부로 보고, 학습 중 thought 성분을 확률 dropout_prob로 빈 "\n\n"으로 대체한다. 어떤 샘플을 skip해도 되는지는 모델마다 추론 능력이 달라 사전에 정하기 어려우므로 random dropout으로 시작하고, 실제 판단은 2단계 RL에 위임한다.

# Algorithm 1 — thought_dropout
def thought_dropout(thought, dropout_prob):
    if random.random() < dropout_prob:
        thought = "\n\n"
    return thought

cold-start thought 데이터는 외부 closed-source API 없이 확보해야 한다. 여러 번 추론해 성공 케이스만 남기는 naïve 방식은 덜 효과적이어서, 정답을 조건으로 주고 추론을 역생성하는 reverse thinking을 쓴다:

T ← πθ(V, Q, S*) (1)

reverse thinking: 정답 S*를 조건으로 CoT를 역생성 → forward 생성보다 정답 정합적인 궤적을 값싸게 얻는 self-distillation 트릭(프롬프트: "답은 출력하지 말고 추론 과정만 간결히 생성하라"). AITZ는 기존 chain-of-action thought(CoAT) 주석을 그대로 쓰고, CLEVR·GeoQA에만 reverse thinking을 적용한다. 기본 dropout_prob = 50%, ablation은 {20%, 50%, 80%}.

SFT 하이퍼파라미터 (Llamafactory full-parameter): cutoff_len 2048 · batch 8 · grad_accum 1 · lr 1.0e-5 · cosine · warmup 0.1 · epoch 2. 3B·7B 모두 15분 이내로 끝나는 매우 가벼운 단계다.

2단계 — GRPO Self-Exploration

SFT는 skip 포맷은 가르치지만 "언제 skip할지"는 미해결로 남긴다. GRPO가 N개 후보 {o1,…,oN}를 샘플링해 그룹 내 정규화 advantage를 계산하고 정책을 업데이트한다:

Ai = ( r(oi) − mean{r(o1),…,r(oN)} ) / std{r(o1),…,r(oN)} (2)
JGRPO(θ) = 𝔼{oi}∼πold (1/N) Σi { min[αiAi, βiAi] − β DKL[πθ ‖ πref] } (3)

αi = πθ(oi|v,q) / πold(oi|v,q) — importance ratio,   βi = clip(αi, 1+ε, 1−ε) — clip된 ratio,   πref — reference 정책. KL 계수 β = 0.04, lr 1e-6, max_completion 2048, temperature 1.0, general/agent는 num_generations 8 · 100 step, math는 num_generations 4 · 300 step. 8×NVIDIA H20 GPU, vLLM 가속.

🔍 리뷰 중 발견 — 식 (3)의 표기

min[αiAi, βiAi]의 부호·순서가 PPO clipped objective의 통상 형태와 다소 어긋나 보인다(원문 조판 그대로). 표준 GRPO/PPO에서는 min 안 두 항 중 하나가 clip된 ratio이며, 이 논문도 그 의도로 읽는 것이 자연스럽다 — 이 해석은 논문 밖 일반론.

보상 설계

outcome reward는 두 성분의 합 ro = rd + rc이고, 최종 보상은 r = rf + ro:

rd(s, g) = 𝟙(s = g)   |   rc(p, b) = 𝟙(p ∈ b)  또는  𝟙(‖p − p*‖2 ≤ θ)

Discrete matching rd: 분류·counting·수학의 이산 출력용 binary reward(예측 s = 정답 g면 1). Continuous matching rc: UI 좌표·grounding의 연속 출력용 — 예측 점 p=[x,y]가 정답 박스 b 안이면 1, 정답 점만 있으면 0–1 정규화 좌표에 거리 임계 θ = 0.14([19]에서 차용) 적용. General/Math VQA는 rf+rd, Agent VQA는 rf+rd+rc.

TON은 GRPO를 어떻게 돕는가 (핵심 통찰)

empty-think T\n\n를 샘플링할 수 있어, 한 그룹 안에 think 응답과 non-think 응답이 공존해 응답의 latent 분포 다양성이 커진다. DAPO가 advantage 분포 Ai(무엇이 좋은 답인가)를 다양화한다면, TON은 정책확률 πθ(oi|v,q)(어떤 형태의 답을 낼까) 쪽의 α, β 다양성을 높인다.

TON 파이프라인: SFT가 "skip이라는 선택지"를 포맷에 심고(seeding), GRPO가 "언제 skip할지"를 reward로 탐색한다.
⚠️ 논문 밖 일반론 / 미명시

"다양성 증가 → 성능 향상"의 인과는 Fig.3의 직관적 도식으로 제시될 뿐 방법론 절에서 정량 ablation으로 분리 검증되지 않는다 (추정). 또 정답을 알고 만든 reverse-thinking 궤적의 distribution shift(사후 정당화된 CoT ≠ 실제 추론 분포) 우려는 논문에 명시되지 않음.

04 · 실험

실험 — 무엇을 보이고, 무슨 결과이며, 어떻게 읽나

공통 설정: Qwen-2.5-VL-Instruct 3B/7B · 8×NVIDIA H20 GPU · vLLM 가속 · greedy 디코딩 평가. CLEVR·AITZ는 100 step, GeoQA는 난이도가 높아 300 epoch 학습. Agent(AITZ)에서는 GRPO를 직접 적용하면 복잡한 출력 포맷 탓에 coordinate reward가 0으로 죽어, baseline에도 동일한 SFT 단계를 넣어 공정 비교한다.

실험은 세 개의 RQ로 짜여 있다 — Q1 효과 있나(성능·효율), Q2 왜 되나(skip 행동이 추론 강도에 적응하나), Q3 꼭 필요한가(SFT 없이 프롬프트만으로 안 되나).

실험 ① — TON vs vanilla GRPO (Q1: 성능·효율)

실험 ③ — Skip ratio의 추이와 OOD overfitting 회피 (Q2)

난이도 인지 dropout vs random dropout

무엇을 보여주나: base VLM zero-shot 정확도로 난이도를 easy(60–100)/medium(40–60)/hard(0–40)로 나눈 뒤, (a) TON의 skip 비율이 난이도를 따라가는지, (b) "easy 샘플만 골라 drop"하는 difficulty-aware 전략이 random보다 나은지. 결과: 쉬운 counting 질의엔 skip 비율↑, 어렵고 지식집약적인 질의엔 skip 비율↓. 그러나 difficulty-aware dropout은 random dropout보다 오히려 근소하게 낮았다(50.5% vs 51.0%).

해석: 수작업 난이도 휴리스틱은 노이즈·편향을 들여와 학습을 방해할 수 있는 반면, random dropout은 더 단순하고 편향 없는 대안으로 과제 전반에 잘 일반화된다. dropout 비율 ablation({20, 50, 80}%)에서도 어느 값이든 skip 비율은 일관되게 증가하되, 20%는 빠르게 상승하고 80%는 학습 내내 안정적이어서 낮은 값에서 출발하는 편이 권장된다.

실험 ④ — SFT가 정말 필요한가 (Q3)

무엇을 보여주나: SFT 없이 "질문이 단순하면 <think>\n\n</think>로 답하라"는 hybrid 프롬프트만 주고 바로 GRPO를 돌리는 대안. 결과: hybrid와 vanilla GRPO의 완성 길이 차이는 미미했고, GRPO가 학습·추론 중 생성한 전체 샘플에서 skip 케이스는 GeoQA 단 2건, AITZ 0건이었다. 부록의 별도 실험(<think>\n\n</think> 출력에 length reward rl=1을 직접 부여)에서도 첫 100 step 내내 length reward가 0에 머물렀다.

🔍 리뷰 중 발견 — RL exploration 붕괴가 진짜 이유

skip 출력을 한 번도 샘플링하지 않으면 그 행동에 reward를 걸어도 gradient가 흐르지 않는다. 즉 thought dropout SFT는 "성능 개선"이 아니라 RL이 탐색할 행동 공간에 skip을 심어두는 부트스트랩(seeding)이라는 것이 핵심이며, 4.2절의 응답 분포 다양성 논의와 정확히 맞물린다(이 "탐색 공간 부트스트랩" 프레이밍 자체는 논문이 명시하지 않은 리뷰 해석).

정성 사례

핵심 takeaway

TON은 modality(counting · 수학 · GUI agent · text-only GSM8K)를 넘나들며 완성 길이를 최대 90% 절감하면서 성능을 유지·향상한다. skip 비율은 학습과 함께 자연스럽게 증가하고 난이도에 따라 갈리며, 어려운 문항에선 추론을 유지한다 — 선택적 추론이 양방향으로 작동함을 정량(Table 2·3·9)·정성(Table 4, Fig.17) 모두로 입증했다.

AdaptMMBench: Benchmarking Adaptive Multimodal Reasoning for Mode Selection and Reasoning Process arXiv:2602.02676 (2026-02)

ARES: Multimodal Adaptive Reasoning via Difficulty-Aware Token-Level Entropy Shaping arXiv:2510.08457 (2025-10)

Learning Adaptive Reasoning Paths for Efficient Visual Reasoning arXiv:2604.14568 (2026-04)
